# 💿 Cozy Vinyl Player for SillyTavern

Уютное расширение для **SillyTavern**, которое добавляет в конец ответов бота интерактивный виниловый мини-плеер под настроение текущей сцены.

A cozy interactive vinyl record player widget for **SillyTavern** roleplay chats — featuring smooth CSS animations, synthesized vinyl crackle & lo-fi notes, and pastel color themes.

---

## ✨ Фишки / Features

* **🎶 Автоматический саундтрек сцены** — бот сам подбирает подходящую песню, исполнителя, вайб и атмосферную строчку под текущий момент ролевой.
* **💿 Интерактивная пластинка** — по клику на карточку иголка проигрывателя плавно опускается на диск, пластинка крутится, прыгает эквалайзер и летят нотки.
* **🔊 Ламповый звук без внешних файлов** — встроенный Web Audio синтезатор создаёт мягкий тёплый треск винила и нежные lo-fi переливы (можно включить/выключить в настройках).
* **🎨 4 цветовые темы** — меняются прямо в меню расширений:
  * ☕ **Тёплый латте** (Warm Latte)
  * 🌸 **Нежная сакура** (Sakura Pink)
  * 🌙 **Ночной Lo-Fi** (Midnight Lo-Fi)
  * 🍵 **Уютная матча** (Cozy Matcha)

---

## 📦 Установка / Installation

1. Откройте **SillyTavern**.
2. Перейдите во вкладку **Extensions** (иконка кубика сверху) → **Install extension**.
3. Вставьте ссылку на этот репозиторий в поле **Git URL** и нажмите **Save / Install**.

---

## 🪄 Как это работает / Tag Format

Расширение автоматически добавляет инструкцию для бота (можно отключить в настройках `🎵 Cozy Vinyl Player`).

Формат тега, который превращается в плеер:
```text
[vinyl: Название трека | Исполнитель | 🌧️ Вайб сцены | Короткая строчка из песни или описание атмосферы]
```

**Пример:**
```text
[vinyl: Sweater Weather | The Neighbourhood | 🌧️ Уютный вечер | На улице дождь, но в одном свитере на двоих совсем не холодно]
```

---

## ⚙️ Настройки / Settings

В панели **Extensions → 🎵 Cozy Vinyl Player** можно настроить:
* **Авто-промпт для бота** — автоматическая отправка инструкции формата `[vinyl: ...]`.
* **Звук винила и lo-fi при клике** — включение/отключение звукового синтезатора.
* **Крутить пластинку сразу** — запускать анимацию вращения сразу при появлении сообщения.
* **Тема плеера** — выбор одной из 4 палитр оформления.
